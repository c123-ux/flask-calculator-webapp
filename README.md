# 🧮 Flask 网页计算器

一个基于 Flask 前后端分离的简易网页计算器，支持四则运算、历史记录和智能交互功能。

## 📁 项目结构

```
D:\PythonProject2\
├── app.py                 # Flask 后端主程序
├── requirements.txt       # Python 依赖
├── history.json           # 计算历史数据（自动创建）
├── templates/
│   └── index.html         # HTML 模板
├── static/
│   ├── css/
│   │   └── style.css      # 样式文件
│   └── js/
│       └── script.js      # 前端交互逻辑
└── main.py                # 原有文件（可忽略）
```

## 🎯 API 接口说明

### 1. 执行计算
- **URL**: `POST /api/calculate`
- **请求体**:
```json
{
  "num1": "10",
  "num2": "5",
  "operator": "+"
}
```
- **响应**:
```json
{
  "success": true,
  "result": "15",
  "expression": "10 + 5 = 15"
}
```

### 2. 获取历史记录
- **URL**: `GET /api/history`
- **响应**:
```json
{
  "success": true,
  "data": [
    {
      "expression": "10 + 5 = 15",
      "timestamp": "2026-05-14 10:30:00"
    }
  ]
}
```

### 3. 清空历史记录
- **URL**: `POST /api/history/clear`
- **响应**:
```json
{
  "success": true,
  "message": "历史记录已清空"
}
```

## 📝 开发笔记

### 架构设计
```
      POST /api/calculate      
   前端页面        Flask API  
  (index.html)    (app.py)   
   script.js                   
      JSON 响应                  
                                                      
                                              
                                                计算历史    
                                                (history.json)
```

**核心思路**：把计算逻辑从 JS 搬到 Python，前端只做界面展示，每次点击 = 都发请求给后端计算并保存记录。

### 关键代码说明

1. **后端计算逻辑** (`app.py`)
   - 参数验证（完整性 + 数据类型）
   - 执行四则运算
   - 精度处理（round 到 10 位小数）
   - 整数格式化（去掉末尾的 .0）
   - 保存到 JSON 文件（最多 50 条）

2. **前端调用** (`script.js`)
   - 使用 Fetch API 发送 POST 请求
   - 显示 loading 状态
   - 错误处理和用户提示
   - 自动刷新历史记录
   - 结果淡入动画
   - 历史回填功能
   - 连续运算本地累积

3. **数据持久化**
   - 使用 `history.json` 文件存储
   - 自动创建和读取
   - 最多保留 50 条记录
   - 服务器重启后数据不丢失

4. **智能显示**
   - 数字长度检测
   - 自动切换字体大小
   - 超长数字转科学计数法
   - 千分位格式化

## 🐛 常见问题

### Q: 为什么需要后端？
A: 
- 学习 Flask 框架
- 实现数据持久化
- 前后端分离架构实践
- 为后续扩展（用户系统、云同步等）打基础

### Q: 历史记录保存在哪里？
A: 保存在项目根目录的 `history.json` 文件中，服务器重启后数据不会丢失。

### Q: 可以部署到服务器吗？
A: 可以！只需：
1. 安装依赖
2. 运行 `python app.py`
3. 配置 Nginx 反向代理（可选）
4. 使用 Gunicorn 生产环境部署（推荐）

### Q: 为什么直接双击 index.html 打不开？
A: 因为使用了 Flask 模板语法（`{{ url_for() }}`），必须通过 Flask 服务器渲染后才能正常显示。请访问 `http://localhost:5000`。

### Q: 如何修改端口号？
A: 编辑 `app.py` 最后一行：
```python
app.run(debug=True, host='0.0.0.0', port=5001)  # 改成 5001
```
